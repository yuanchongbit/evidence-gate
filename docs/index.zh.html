证据之门

提示稀释并旋转视觉语言模型的
证据轴

Chong Yuan

代码 论文 结果 局限 BibTeX

一句话。问视觉语言模型一个图中并不存在的物体，它通常回答不确定。只要加一句话——“提示：雨伞是黑色的。”——它就会回答黑色。我们表明，这不是“没看见”：证据在模型内部仍然可解码，但提示把存在-缺失均值差缩短，并让它偏离无提示线性读出的方向 24°–86°（下图的 3B 为 40°）；坏掉的是把证据转成拒答的那道门。这道门写得很晚，位于网络最后三分之一（69–94% 深度），可以被读出，也可以沿单一方向推回去。同一套几何在来自三个语言模型家族的五个骨干上重现；模型自身置信度的塌缩出现在 Qwen 与 Phi 的读出里，却不在 Gemma 里，因此它是读出特有的，而不是家族共有的。

一张图，六种提问，不改图

每张照片都会出现在 2×3 被试内设计的全部六个格子里：视觉证据 {物体存在，物体标注缺失} × 文本提示 {无，提示 a，提示 b}。存在行里，提示 a 是物体的真实颜色，提示 b 是刻意远离的色相；缺失行里没有“正确颜色”，提示 a 是该缺失类别在 COCO val 中常见的颜色，提示 b 是远端色相。

“缺失”这一臂不是靠擦除像素做出来的。它询问的物体类别，被 COCO val2017 的穷尽标注判定为不在图中，因此场景本身没有改动。一个独立的 yes/no 探针确认了操纵有效：对缺失类别 p(yes) = 0.095，而原图为 0.95。这里的“缺失”是标注层面的，不等同于模型感知到的缺失。

与画面一致的提示会帮到模型（准确率 0.762 → 0.973），正因如此，冲突提示才能算因果操纵，而不是噪声。

Qwen 与 Phi 的输出读出坍塌；五个骨干的证据轴都被稀释并旋转

在冲突提示下，三个以 Qwen 为语言模型的骨干（两个 Qwen2.5-VL 尺寸，以及语言模型为 Qwen2-7B 的 LLaVA-OneVision）上，其输出分布中的所有信号都失去了区分“有证据”与“无证据”的能力。最终隐状态上的线性探针在留出场景上保住了大部分排序（3B 0.958、7B 0.946、LLaVA 0.935，远端色相提示）；但它区分存在与缺失的间隔从 15.9 缩到 7.3，完整的均值差向量既变短又转向。信息是被重新编码，而不是被抹掉。Gemma-3-4B-it（Gemma-3 + SigLIP 编码器，不含任何 Qwen 组件）复现了同一套几何，却没有复现输出坍塌：它的 p(unknown) AUROC 只从 0.961 降到 0.891，最大概率反而从 0.627 升到 0.701，而留出探针迁移为 0.964 / 0.970。Phi-3.5-vision（Phi-3 + CLIP 编码器）是相反的例子：它会拒答（0.897），也会被提示带偏（0.322 / 0.425），证据向量旋转 86° / 74°，使无提示探针跌到 0.685 / 0.675，但在同样的状态上重拟合仍有 0.998，而它自身的信号塌到随机水平以下（0.939 → 0.385 / 0.458）。

抑制发生在后段，证据被稀释并旋转

冲突下，探针区分存在与缺失的间隔从 15.9 缩到 7.3，而类内离散度只缩小到 0.62–0.83（均值间隔为 0.20–0.69）。在完整状态空间里（见下表），存在-缺失均值差在四个参与拟合的模型里只剩 0.39–0.64 的长度，并偏离无提示方向 24°–71°；两种冲突颜色旋转到几乎相同的方向（Qwen 模型 cos 0.91，Gemma 0.97）。用类内噪声白化后，可分性并未下降，冲突对内部重拟合的探针达到 0.989–0.999：证据是被重新编码，而不是被摧毁。这解释了为什么 p(unknown) 会失效——它读的是绝对尺度和一个固定方向——而基于排序的门仍然有效。敏感性损失可以从几何预测：在 12 个“模型×条件”单元上，d′c/d′0 = 1.42 ×（均值间隔比）+ 0.003（R² = 0.918），每个模型的增益在 1.25–1.60 之间，因为类内离散度的收缩几乎与条件无关（0.71 ± 0.07）。增益不跨模型共享，而且这一规律止于读出层：它不预测模型自身置信度的坍塌。把探针换成只用输出计算的行为 d′，这一恒等式就不再成立：在八个提示格上，行为比值同样跟随 gap 比值（斜率 0.97、截距 0.12，R² = 0.57；过原点 1.27），模型相关增益为 0.92（3B）、1.43（7B）、1.62（LLaVA）、1.40（Gemma）。样本外检验：当每个模型的增益在本模型内估计时，探针规律成立（留一单元误差 0.056，单位斜率基线为 0.179；场景 bootstrap 斜率 1.42 [1.37, 1.47]），但增益不能外推到未见的模型（留一模型误差 0.02–0.12）；行为侧的拟合是描述性的而非预测性的（留一单元 0.100，基线 0.121–0.125）。

最终隐状态上完整的“存在 − 缺失”均值差向量（261 个场景；场景 bootstrap 置信区间见论文）。a 为可信提示，b 为远端色相提示。同一估计量在无提示向量自比时给出长度比 1.00、夹角 3–5°，即噪声底。逐场景间隔失去了跨场景一致性，而归一化后的可分性并未下降：聚合向量变短，一部分是因为不同场景不再指向同一方向。Gemma-3-4B-it（Gemma-3 + SigLIP，不含任何 Qwen 组件）复现了稀释、旋转、与颜色无关的方向（cos 0.97）和留出场景迁移（0.964 / 0.970），但没有复现输出信号的塌缩：冲突下它的最大概率反而上升（0.627 → 0.701），而答案被带偏的程度与 3B 相当（准确率 0.567 → 0.241）。Phi-3.5-vision 把这一几何推到最远：旋转到 86° / 74° 时，无提示探针跌到 0.685 / 0.675，而重拟合达到 0.998，它自身的信号塌到 0.385 / 0.458。因此内部几何跨三个语言模型家族、三种视觉编码器成立；输出坍塌出现在 Qwen 与 Phi 的读出里但不在 Gemma 里，是读出特有的而非家族共有的。在 PASCAL VOC 2012 上（180 张图，自动标签，同一 3B 检查点）复现了行为、留出迁移（0.925 / 0.950）、几何（0.41 / 0.52，35° / 33°）与门（25% 覆盖率下 0.367 → 0.144）。

两个干预检验这一分离的因果地位。沿探针方向 w，加上 +0.5·‖h‖ 会把“物体缺失”时的拒答从 0.904 压到 0.000；减去 0.5·‖h‖ 会把“物体存在”时的拒答从 0.011 抬到 0.352。剂量–响应是单调的，并且当方向在一半场景上拟合、在另一半上评估时依然成立。

同一方向在提示存在时依然有效。在冲突提示的前向过程中，−0.25·‖h‖ 把“物体缺失”时的拒答从 0.542 抬到 0.874；+0.25·‖h‖ 把答对真实颜色的比例从 0.383 提到 0.479，而采纳提示的比例仍为 0.433。冲突稀释、旋转并削弱证据的权重，但没有切断它与决策的连接。由于向量在 unembedding 之前注入，这是读出层面的因果证据。

两个控制限定了这一结论。去掉 w 使缺失项拒答下降 0.215 / 0.211 / 0.102（3B / 7B / LLaVA）、提示采纳上升 0.201 / 0.209 / 0.113，而去掉三个随机方向时所有指标的变化不超过 0.015。但这个比值不能解释为方向特异性：两种投影去掉的状态量不同。平均绝对投影比例为 w 的 0.055，随机方向为 0.019 / 0.004 / 0.008，相差 5.4 倍；与类别结构对齐的方向去掉的能量相当（类均值 0.052，第一主成分 0.066）。把去除能量对齐之后，大部分效应消失：把 w 缩放到随机方向的能量，缺失拒答只变化 −0.073（3B）和 −0.018（7B）；把随机方向放大到 w 的能量，3B 无效应（+0.010），7B 反而比 w 更大（−0.044）；类均值与第一主成分在对齐能量后使 3B 上升 +0.083、对 7B 无影响（+0.004）。注入同样不特异：同范数随机方向也能把门推开。因此可辩护的结论是读出层面的充分性，而不是已识别的回路；w 在 Qwen 家族与 Phi 中是高效的读出方向，但在 Gemma 中任何同范数扰动都能移动这道门。对两个非 Qwen 模型做去除能量对齐后，注入效率与必要性分离。Gemma 的原始消融为零（0.437，基线 0.439），两种对齐版本仍为零，而类均值与第一主成分在对齐到 w 的能量后各使拒答上升 +0.021：决定头部读出的是类别结构，不是 w。Phi 的原始效应（−0.057）主要来自被去除的能量：缩放到随机方向的能量后只剩 −0.013，而随机方向放大到 w 的能量后变化更大且方向相反（+0.048），类均值与第一主成分在对齐能量后分别使拒答下降 0.157 / 0.249。注入有效与去除相关是两件事。

这一效应在另外两个冲突策略完全相反的模型上同样成立。Qwen2.5-VL-7B 过度拒答（缺失时拒答 0.918），−0.25·‖h‖ 把它抬到 1.000，+0.25·‖h‖ 压到 0.057；LLaVA-OneVision-7B 几乎不拒答（缺失 0.138，存在 0.004），同样的扫描得到 0.734 和 0.000。打开这道门并不等于给出答案：LLaVA 更采纳提示（缺失项 0.833 → 0.990），但存在项的真实颜色率没有统计上显著变化（+0.019）；7B 恢复了部分真实答案（0.249 → 0.421），但提示采纳也上升（0.176 → 0.425）。这个方向控制的是一道“是否弃答”的门，而不是答案选择。

因果控制同样跨模型复现。剂量匹配的层注入在第 16 层（3B）和第 20 层（7B）之前都不起作用，只在第 32 / 26 层显著；LLaVA 的起点更早（第 20 层），但仍落在最后 30% 的深度内。同图、反问题的替换控制在 L24/L26 给出配对恢复差：3B +0.51 / +0.83，7B +0.84 / +0.86，LLaVA +0.74 / +0.80，Gemma +0.71 / +0.77，Phi +0.71 / +0.77；而打乱来源的恢复量至少一样多——末层状态携带的是它所对应问题的策略，而不是这张图证据的编码。读出层的方向注入同样在 Qwen 家族之外复现，只是幅度不同：±0.50·‖h‖ 使 Gemma 的缺失项拒答变化 +0.056 / −0.109（其存在项已处在 0.008 的拒答地板），使 Phi 变化 +0.435 / −0.330；Phi 在冲突下存在项仍有 0.548 的拒答率，说明它的门对“问的是缺失项”并不够特异。头部的随机方向控制进一步限定了这一点：拟合方向在 Phi 是随机方向平均效应的 3.0 倍（消融为 12.9 倍），在 Gemma 却只有 0.55 倍；Gemma 消融 w 为零效应（−0.002），尽管它去掉的能量是随机投影的 5.9 倍。层注入在 Gemma 只有 L30 干净（±0.25 时缺失拒答 −0.151 / +0.088，存在项 gold 与提示采纳不变；L16 和 L24 的负方向虽移动门却破坏存在项），而 Phi 的方向在 L14 已经起作用（−0.193 / +0.180），越深越弱，尽管替换恢复在 L14 只有 31%、L22 才达到 97%。Gemma 的头部是“可移动但非方向特异”的读出；Phi 的早期注入说明这条轴在冲突效应被定位之前就已可用，而不是它被计算的位置。

括号提示词不是原因：旋转是通用的，压缩与查询相关

另外五种提示形式在不带 Hint: 括号前缀的情况下承载同一断言：同事转述、裸陈述、第一人称信念、系统消息断言和两轮对话。在 Qwen2.5-VL-3B/7B 与 Gemma-3-4B 中，证据轴在每种形式下都缩短到无提示长度的 0.38–0.89，并旋转 16°–47°；两种提示颜色给出几乎平行的冲突轴（cos 0.91–0.999），在括号形式上拟合的探针迁移到其他每种形式，AUROC 为 0.95–0.999。随位置改变的是读出策略，而不是几何：3B 的提示采纳在 0.042–0.885 之间，7B 在所有形式中不超过 0.05，Gemma 的顺序则相反。长度比在形式间预测错误提示下的准确率，r = +0.89 / +0.89 / +0.98（3B / 7B / Gemma），而它与提示采纳的关系没有一致符号。

三个句子对照进一步把“查询内容”与“多加的句子”分开。在同事转述模板的两个证据臂中加入同一句、均不带提示：中性句（“A colleague mentioned that the room is quiet.”）使 3B 的证据轴移动 42.7° [41.4, 44.2]，与关于被问类别的冲突断言（44.2°）一样远，因此旋转是改写提示的相关物，而不是冲突特有的。压缩才是与查询相关的特征：三个模型中证据轴都随查询相关度单调缩短——中性句、其他物体断言、颜色固定的被问类别断言、冲突断言依次为 0.822 / 0.804 / 0.604 / 0.589（3B）、0.730 / 0.691 / 0.596 / 0.568（7B）、1.000 / 0.897 / 0.877 / 0.885（Gemma）。关于其他物体的颜色词不够，必须点名被问类别。颜色固定的查询轴与冲突轴几乎共线（cos 0.976 / 0.988 / 0.997），所以两臂间改变颜色只带来很小的额外缩短（3B 0.015，7B 0.028，Gemma 为零）。行为在 3B 中随之变化：存在证据时，准确率依次为 0.762 → 0.736 → 0.705 → 0.571 → 0.567（无提示、中性句、其他物体、颜色固定的查询句、冲突），查询句把陈述颜色的采纳率从 12.3% 提高到 21.8%。Gemma 只在查询句下下降（0.552 / 0.563 → 0.521），7B 的准确率基本持平而采纳率从 7.7% 升到 14.9%。因此冲突效应被描述为证据轴的压缩、且按查询相关度分级；旋转只是改写提示的非特异相关物；跨形式追踪冲突准确率的是长度比，而不是角度。

把机制变成一道门

编造 = 被问物体不存在时仍回答出一种颜色。探针只在无提示场景上拟合，并在留出场景上评分，因此评估场景不贡献任何标签。在共同的 25% 实际回答覆盖率下，用探针而不是模型自身的置信度来排序，能在提示被污染时去掉大部分编造。50% 覆盖率下，3B、LLaVA 与 Gemma 的优势仍在，但 7B 会拒答 72% 的冲突条目，根本到不了这个工作点，Phi 则需要选中 82% 的条目才能答满一半。

LLaVA 对提示的敏感性高得多：冲突下它的存在项拒答率为 0.004、缺失项为 0.138，而 Qwen2.5-VL-7B 分别为 0.556 与 0.918。但恢复集中在相同的相对深度上，且五个模型的轴都在收缩。Gemma-3-4B 与 Phi-3.5-vision 的转折出现得更晚：Gemma 在 47% / 71% / 88% 深度恢复 12% / 90% / 101%，Phi 在 44% / 69% / 88% 恢复 31% / 97% / 102%；它们分别有 34 与 32 个 block，而 Qwen-7B 与 LLaVA 只有 28 个。决定剖面的是深度比例，不是层数。敏感性与作用位点可以分离：更容易被带偏的模型，拥有的是同一道门，只是被推得更开。

我们不主张什么

门的优势有一部分来自“问法不同”

类别匹配对照在同一对里固定被问类别与被断言的颜色。输出坍塌、条件内重拟合与几何都保留，但冻结探针相对 p(unknown) 的边际从 +0.123 / +0.142 / +0.142 降到 +0.050 / +0.002 / −0.015（3B / 7B / LLaVA）；25% 实际回答覆盖率下，它的编造优势在 3B 从 0.115 缩到 0.069，在 7B 消失，在 LLaVA 反转。Gemma 在固定问法下的边际也反转（−0.009）；Phi 的 +0.145 为正，只是因为它自身的信号低于随机水平，工作点上两者只差 0.008。因此主设计的一部分优势来自两个分支问的是不同问题，而不只是证据本身。

不是“普适更好的置信度”

在 VizWiz 天然不可答的问题上，模型自身的 p(unknown) 与冻结探针相当（0.878 vs. 0.827）。探针仍然优于最大概率（0.437），但它相对 p(unknown) 的优势只存在于“提示攻击拒答门”的场景里。

是排序不变，不是校准不变

在 VQA-v2 颜色题上，冻结探针的平均分在冲突下从 +6.93 变为 +2.10，但排序保持不变。我们主张的是 AUROC 不变，而非分数不变。

是证据，不是正确性

探针回答的是“证据在不在？”，而不是“答案对不对？”。无提示时判断答案正确性，最大概率是更好的信号。

“缺失”不等于“不合场景”

缺失类别采样时没有约束场景合理性，而基于 COCO 共现的打分能预测无提示拒答（更匹配的一半拒答分别低 0.116 / 0.069 / 0.132，对应 3B / 7B / LLaVA）。类别频率与它只有弱相关（Spearman 0.23），也解释不了它：两者联合拟合后，场景匹配在三个模型里都保持负向，频率只在 7B 有额外贡献。两半内部的证据判别都还在：p(unknown) AUROC 至少 0.976，探针至少 0.989。场景匹配改变的是门的水平，不是证据的排序。

颜色才是深度检验

左右与计数任务复现了“门被打开”，但没有复现完整的读出坍塌；它们是边界条件。机制层面的结论在颜色任务上最强。

读出层面的因果证据

干预在 unembedding 之前注入，替换对照的打乱来源是标签匹配的。我们主张的是读出层面的充分性与恢复位点，而不是完整的上游机制。

输出坍塌是模型相关的

Gemma-3-4B 对证据轴的稀释与旋转和 Qwen 模型一样强，但它自身的置信度几乎没有退化（p(unknown) AUROC 0.961 → 0.891，最大概率 0.627 → 0.701），而答案照样被带偏；Phi-3.5-vision（Phi-3 + CLIP）是另一方向的对照：稀释到长度的 0.05 / 0.15，旋转 86° / 74°，自身信号塌到 0.385 / 0.458，冻结探针跌到 0.685 / 0.675，而重拟合达到 0.998。因此驱动“冻结门”这一动机的输出坍塌出现在 Qwen2/2.5 与 Phi-3 的读出里，却不在 Gemma 里，是读出特有的，而不是绑定于某一个语言模型家族。在 Gemma 上探针相对 p(unknown) 的优势更小（0.964 vs. 0.891），但仍然存在。再往下的骨干 SmolVLM-Instruct 根本不会拒答，因此无法检验这道门。
