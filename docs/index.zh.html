证据之门

提示稀释并旋转视觉语言模型的
证据轴

yuanchongbit

代码 论文 结果 局限 BibTeX

一句话。问视觉语言模型一个图中并不存在的物体，它通常回答不确定。只要加一句话——“提示：雨伞是黑色的。”——它就会回答黑色。我们表明，这不是“没看见”：证据在模型内部仍然可解码，但提示把存在-缺失均值差缩短，并让它偏离模型原本读取的方向 24°–71°（下图的 3B 为 40°）；坏掉的是把证据转成拒答的那道门。这道门写得很晚，位于最后几层，可以被读出，也可以沿单一方向推回去。同一套几何在来自两个语言模型家族的四个骨干上重现；只有模型自身置信度的塌缩是 Qwen 读出所特有的。

一张图，六种提问，不改图

每张照片都会出现在 2×3 被试内设计的全部六个格子里：视觉证据 {物体存在，物体标注缺失} × 文本提示 {无，提示 a，提示 b}。存在行里，提示 a 是物体的真实颜色，提示 b 是刻意远离的色相；缺失行里没有“正确颜色”，提示 a 是该缺失类别在 COCO val 中常见的颜色，提示 b 是远端色相。

“缺失”这一臂不是靠擦除像素做出来的。它询问的物体类别，被 COCO val2017 的穷尽标注判定为不在图中，因此场景本身没有改动。一个独立的 yes/no 探针确认了操纵有效：对缺失类别 p(yes) = 0.095，而原图为 0.95。这里的“缺失”是标注层面的，不等同于模型感知到的缺失。

与画面一致的提示会帮到模型（准确率 0.762 → 0.973），正因如此，冲突提示才能算因果操纵，而不是噪声。

Qwen 家族的输出读出坍塌；四个骨干的证据轴都被稀释并旋转

在冲突提示下，三个以 Qwen 为语言模型的骨干（两个 Qwen2.5-VL 尺寸，以及语言模型为 Qwen2-7B 的 LLaVA-OneVision）上，其输出分布中的所有信号都失去了区分“有证据”与“无证据”的能力。最终隐状态上的线性探针在留出场景上保住了大部分排序（3B 0.958、7B 0.946、LLaVA 0.935，远端色相提示）；但它区分存在与缺失的间隔从 15.9 缩到 7.3，完整的均值差向量既变短又转向。信息是被重新编码，而不是被抹掉。第四个骨干 Gemma-3-4B-it（Gemma-3 + SigLIP 编码器，不含任何 Qwen 组件）复现了同一套几何，却没有复现输出坍塌：它的 p(unknown) AUROC 只从 0.961 降到 0.891，最大概率反而从 0.627 升到 0.701，而留出探针迁移为 0.964 / 0.970。

抑制发生在后段，证据被稀释并旋转

冲突下，探针区分存在与缺失的间隔从 15.9 缩到 7.3，而类内离散度基本不变。在完整状态空间里（见下表），存在-缺失均值差只剩 0.39–0.64 的长度，并偏离无提示方向 24°–71°；两种冲突颜色旋转到几乎相同的方向（Qwen 模型 cos 0.91，Gemma 0.97）。用类内噪声白化后，可分性并未下降，冲突对内部重拟合的探针达到 0.989–0.999：证据是被重新编码，而不是被摧毁。这解释了为什么 p(unknown) 会失效——它读的是绝对尺度和一个固定方向——而基于排序的门仍然有效。

最终隐状态上完整的“存在 − 缺失”均值差向量（261 个场景；场景 bootstrap 置信区间见论文）。a 为可信提示，b 为远端色相提示。同一估计量在无提示向量自比时给出长度比 1.00、夹角 3–5°，即噪声底。逐场景间隔失去了跨场景一致性，而归一化后的可分性并未下降：聚合向量变短，一部分是因为不同场景不再指向同一方向。Gemma-3-4B-it（Gemma-3 + SigLIP，不含任何 Qwen 组件）复现了稀释、旋转、与颜色无关的方向（cos 0.97）和留出场景迁移（0.964 / 0.970），但没有复现输出信号的塌缩：冲突下它的最大概率反而上升（0.627 → 0.701），而答案被带偏的程度与 3B 相当（准确率 0.567 → 0.241）。内部几何跨语言模型家族成立；排序-尺度分离是本组 Qwen2/2.5 读出的性质。

两个干预检验这一分离的因果地位。沿探针方向 w，加上 +0.5·‖h‖ 会把“物体缺失”时的拒答从 0.904 压到 0.000；减去 0.5·‖h‖ 会把“物体存在”时的拒答从 0.011 抬到 0.352。剂量–响应是单调的，并且当方向在一半场景上拟合、在另一半上评估时依然成立。

同一方向在提示存在时依然有效。在冲突提示的前向过程中，−0.25·‖h‖ 把“物体缺失”时的拒答从 0.542 抬到 0.874；+0.25·‖h‖ 把答对真实颜色的比例从 0.383 提到 0.479，而采纳提示的比例仍为 0.433。冲突稀释、旋转并削弱证据的权重，但没有切断它与决策的连接。由于向量在 unembedding 之前注入，这是读出层面的因果证据。

两个控制限定了这一结论。去掉 w 使缺失项拒答下降 0.215 / 0.211 / 0.102（3B / 7B / LLaVA）、提示采纳上升 0.201 / 0.209 / 0.113，而去掉三个随机方向时所有指标的变化不超过 0.015。但这个比值不能解释为方向特异性：两种投影去掉的状态量不同。平均绝对投影比例为 w 的 0.055，随机方向为 0.019 / 0.004 / 0.008，相差 5.4 倍；与类别结构对齐的方向去掉的能量相当（类均值 0.052，第一主成分 0.066）。把去除能量对齐之后，大部分效应消失：把 w 缩放到随机方向的能量，缺失拒答只变化 −0.073（3B）和 −0.018（7B）；把随机方向放大到 w 的能量，3B 无效应（+0.010），7B 反而比 w 更大（−0.044）；类均值与第一主成分在对齐能量后使 3B 上升 +0.083、对 7B 无影响（+0.004）。注入同样不特异：同范数随机方向也能把门推开。因此可辩护的结论是读出层面的充分性、w 是一条高效的读出方向，而不是已识别的回路。

这一效应在另外两个冲突策略完全相反的模型上同样成立。Qwen2.5-VL-7B 过度拒答（缺失时拒答 0.918），−0.25·‖h‖ 把它抬到 1.000，+0.25·‖h‖ 压到 0.057；LLaVA-OneVision-7B 几乎不拒答（缺失 0.138，存在 0.004），同样的扫描得到 0.734 和 0.000。打开这道门并不等于给出答案：LLaVA 更采纳提示（缺失项 0.833 → 0.990），但存在项的真实颜色率没有统计上显著变化（+0.019）；7B 恢复了部分真实答案（0.249 → 0.421），但提示采纳也上升（0.176 → 0.425）。这个方向控制的是一道“是否弃答”的门，而不是答案选择。

因果控制同样跨模型复现。剂量匹配的层注入在第 16 层（3B）和第 20 层（7B）之前都不起作用，只在第 32 / 26 层显著；LLaVA 的起点更早（第 20 层），但仍落在最后 30% 的深度内。同图、反问题的替换控制在 L24/L26 给出配对恢复差：3B +0.51 / +0.83，7B +0.84 / +0.86，LLaVA +0.74 / +0.80；而打乱来源的恢复量至少一样多——末层状态携带的是它所对应问题的策略，而不是这张图证据的编码。

把机制变成一道门

编造 = 被问物体不存在时仍回答出一种颜色。在固定 50% 覆盖率下，用探针而不是模型自身的置信度来排序，能去掉大部分编造——但只在提示被污染时成立。把三种提示条件合并后，优势从 23× 缩到 3×（0.064 vs. 0.193）；而固定分数阈值会因轴收缩而在冲突下变得过于保守。

同样的模式也出现在 Qwen2.5-VL-7B（冻结探针 0.126 vs. p(unknown) 0.268）和 LLaVA-OneVision-7B（0.111 vs. 0.295）上。探针的优势来自隐状态本身：对同样的 12 维输出概率做逻辑回归读出，冲突下 50% 覆盖率的编造率为 0.142。重拟合探针在 3B 上达到 0.011，但这是上界而非可部署分数。优势在 5%–50% 的不可答比例下保持；10% 的保形风险证书在 3B 与 LLaVA 上成立，5% 在 130 个校准场景下不可行。

LLaVA 对提示的敏感性高得多：冲突下它的存在项拒答率为 0.004、缺失项为 0.138，而 Qwen2.5-VL-7B 分别为 0.556 与 0.918。但恢复集中在相同的相对深度上，且三个模型的轴都在收缩。敏感性与作用位点可以分离：更容易被带偏的模型，拥有的是同一道门，只是被推得更开。Gemma-3-4B 只做了几何、探针迁移与信号检测，没有做逐层扫描，因此深度剖面建立在这三个模型上。

我们不主张什么

不是“普适更好的置信度”

在 VizWiz 天然不可答的问题上，模型自身的 p(unknown) 与冻结探针相当（0.878 vs. 0.827）。探针仍然优于最大概率（0.437），但它相对 p(unknown) 的优势只存在于“提示攻击拒答门”的场景里。

是排序不变，不是校准不变

在 VQA-v2 颜色题上，冻结探针的平均分在冲突下从 +6.93 变为 +2.10，但排序保持不变。我们主张的是 AUROC 不变，而非分数不变。

是证据，不是正确性

探针回答的是“证据在不在？”，而不是“答案对不对？”。无提示时判断答案正确性，最大概率是更好的信号。

“缺失”不等于“不合场景”

缺失类别采样时没有约束场景合理性，而基于 COCO 共现的打分能预测无提示拒答（更匹配的一半拒答分别低 0.116 / 0.069 / 0.132，对应 3B / 7B / LLaVA）。类别频率与它只有弱相关（Spearman 0.23），也解释不了它：两者联合拟合后，场景匹配在三个模型里都保持负向，频率只在 7B 有额外贡献。两半内部的证据判别都还在：p(unknown) AUROC 至少 0.976，探针至少 0.989。场景匹配改变的是门的水平，不是证据的排序。

颜色才是深度检验

左右与计数任务复现了“门被打开”，但没有复现完整的读出坍塌；它们是边界条件。机制层面的结论在颜色任务上最强。

读出层面的因果证据

干预在 unembedding 之前注入，替换对照的打乱来源是标签匹配的。我们主张的是读出层面的充分性与恢复位点，而不是完整的上游机制。

输出坍塌是模型相关的

Gemma-3-4B 对证据轴的稀释与旋转和 Qwen 模型一样强，但它自身的置信度几乎没有退化（p(unknown) AUROC 0.961 → 0.891，最大概率 0.627 → 0.701），而答案照样被带偏。驱动“冻结门”这一动机的输出坍塌，是 Qwen2/2.5 读出的性质；在 Gemma 上探针相对 p(unknown) 的优势更小（0.964 vs. 0.891），但仍然存在。再往下的骨干 SmolVLM-Instruct 根本不会拒答，因此无法检验这道门。
