证据之门

视觉语言模型如何在没有证据时
作出回答

yuanchongbit

代码 论文 结果 局限 BibTeX

一句话。问视觉语言模型一个图中并不存在的物体，它通常回答不确定。只要加一句话——“提示：雨伞是黑色的。”——它就会回答黑色。我们表明，这不是“没看见”：证据在模型内部仍然线性可解码，坏掉的是把证据转成拒答的那道门。这道门写得很晚，位于最后几层，可以被读出，也可以沿单一方向推回去。

一张图，六种提问，不改图

每张照片都会出现在 2×3 被试内设计的全部六个格子里：视觉证据 {物体存在，物体经核验不存在} × 文本提示 {无，正确，冲突}。

“缺失”这一臂不是靠擦除像素做出来的。它询问的物体类别，被 COCO val2017 的穷尽标注判定为不在图中，因此场景本身没有改动。一个独立的 yes/no 探针确认了操纵有效：对缺失类别 p(yes) = 0.095，而原图为 0.95。

提示被做得“可信”而非“对抗”：它给出该缺失类别在 COCO val 中最常见的颜色。正确提示会帮到模型（准确率 0.762 → 0.973），正因如此，冲突提示才能算因果操纵，而不是噪声。

读出坍塌，表征不动

在冲突提示下，任何由模型输出分布计算出的信号，都失去了区分“有证据”与“无证据”的能力。而最终隐状态上的线性探针纹丝不动。

抑制是一次“晚写”

我们在未被污染的“无提示”前向传播中取出末位 token 的状态，把它粘贴到带提示传播的第 L 层。如果后续层仍然产生拒答，就说明证据是被带过去的，而不是被重新计算的。

两个对照干预闭合了因果链。沿探针方向 w，加上 +0.5·‖h‖ 会把“物体缺失”时的拒答从 0.904 压到 0.000；减去 0.5·‖h‖ 会把“物体存在”时的拒答从 0.011 抬到 0.352。剂量–响应是单调的，并且当方向在一半场景上拟合、在另一半上评估时依然成立。

同一方向在提示存在时依然有效。在冲突提示的前向过程中，−0.25·‖h‖ 把“物体缺失”时的拒答从 0.542 抬到 0.874；+0.25·‖h‖ 把答对真实颜色的比例从 0.383 提到 0.479，而采纳提示的比例仍为 0.433。冲突削弱的是证据的权重，而不是证据与决策之间的连接。

这一效应在另外两个冲突策略完全相反的模型上同样成立。Qwen2.5-VL-7B 过度拒答（缺失时拒答 0.918），−0.25·‖h‖ 把它抬到 1.000，+0.25·‖h‖ 压到 0.057；LLaVA-OneVision-7B 几乎不拒答（缺失 0.138，存在 0.004），同样的扫描得到 0.734 和 0.000。打开这道门并不等于给出答案：LLaVA 更采纳提示（缺失项 0.833 → 0.990），但存在项的真实颜色率没有统计上显著变化（+0.019）；7B 恢复了部分真实答案（0.249 → 0.421），但提示采纳也上升（0.176 → 0.425）。这个方向控制的是一道“是否弃答”的门，而不是答案选择。

把机制变成一道门

编造 = 被问物体不存在时仍回答出一种颜色。在固定 50% 覆盖率下，用探针而不是模型自身的置信度来排序，能去掉大部分编造——但只在提示被污染时成立。

LLaVA 对提示的敏感性高得多：冲突下它的拒答率从 0.820 跌到 0.088，而 Qwen2.5-VL-7B 只从 0.958 动到 0.877。但抑制写在相同的相对深度上。敏感性与作用位点可以分离：更容易被带偏的模型，拥有的是同一道门，只是被推得更开。

我们不主张什么

不是“普适更好的置信度”

在 VizWiz 天然不可答的问题上，模型自身的 p(unknown) 与冻结探针相当（0.878 vs. 0.827）。探针仍然优于最大概率（0.437），但它相对 p(unknown) 的优势只存在于“提示攻击拒答门”的场景里。

是排序不变，不是校准不变

在 VQA-v2 颜色题上，冻结探针的平均分在冲突下从 +6.93 变为 +2.10，但排序保持不变。我们主张的是 AUROC 不变，而非分数不变。

是证据，不是正确性

探针回答的是“证据在不在？”，而不是“答案对不对？”。无提示时判断答案正确性，最大概率是更好的信号。

颜色才是深度检验

左右与计数任务复现了“门被打开”，但没有复现完整的读出坍塌；它们是边界条件。机制层面的结论在颜色任务上最强。
